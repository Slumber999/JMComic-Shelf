> 本项目是 **[lanyeeee/jmcomic-downloader](https://github.com/lanyeeee/jmcomic-downloader) 的二次开发版本（Fork）**。
> 原版是一个很好用的多线程图形界面下载器；本项目在它的基础上补齐了任务管理、内置阅读器、本地书库与界面体验，做成一个完整的桌面客户端。

## 🖥️ 桌面端功能

> **上手三步**：在 `搜索` 里找漫画 → 进 `章节详情` 勾选章节点 `下载勾选章节`（不想下载可以直接点 `阅读` 在线阅读）→ 下载好的漫画在 `本地库存` 里阅读、导出、管理。收藏夹相关功能需要先点顶栏 `登录`。
>
> 出处标记：**原版** = 继承自上游 · **扩展** = 上游已有、本仓库扩展 · **新增** = 本仓库全新加入

### 发现与检索

- **搜索**（原版）：关键词搜索，支持多种排序
- **搜索增强**（新增）：官方分类树、官方常用标签、多标签累加搜索、年月筛选、搜索历史
- **收藏夹**（扩展）：登录后浏览收藏夹，多选 / 全选 / 长列表点选 / 跨页保留，批量下载或批量导出 cbz
- **每周必看**（原版）：按官方每周榜单浏览，直接批量下载
- **本地库存**（扩展）：下载目录 / 导出目录两种来源切换，标签筛选、阅读进度、按体积统计、按体积删除单本
- **本地标签云**（新增）：纯离线聚合已下载漫画的标签，点标签即按它搜索，或在本地库存里筛选

### 下载与任务管理

- **多线程下载**（原版）：图片并发下载、失败自动重试
- **章节勾选**（原版）：在 `章节详情` 勾选任意章节下载，也可以一键下载整本
- **图片格式**（原版）：jpg（体积小、速度快）或 png（无损、体积大）
- **任务暂停 / 继续**（新增）：下载与导出任务都能暂停、继续；暂停在「图片 / 章节边界」生效，不会下载一半
- **任务持久化**（新增）：关闭软件时自动全部暂停，重启后在进度抽屉里手动继续
- **进度抽屉**（扩展）：底部常驻状态栏 + 可展开的下载 / 导出进度面板，支持框选后批量操作

### 导出与分享

- **导出 cbz / pdf**（原版）：把已下载的漫画打包成单文件
- **免下载直出 cbz**（新增）：图片在内存里取回、还原拼图后直接打包，不落下载目录，带图片级进度
- **跳过已存在**（新增）：继续导出时自动跳过已经导好的章节，被打断的那一章从头重来
- **快速阅读器**（新增）：导出成自包含的 HTML 分享包（图片已内联 / 已解压），离线可看，方便直接分享给任何人

### 阅读

- **内置阅读器**（新增）：本地图片 / cbz / **漫画在线阅读**，单页与滚动（条漫）两种模式
- **连续阅读**（新增）：上一章 / 下一章、阅读进度记忆、顶栏「继续阅读」一键回到上次位置
- **预加载与缓存**（新增）：图片级预加载 + 内存缓存，翻页不卡

### 界面与配置

- **列表 / 网格视图**（新增）：漫画列表可切换列表或网格（4 列大封面，按钮悬停才显示），偏好本地保存
- **封面悬停预览**（新增）：列表模式下鼠标放到封面上，右侧贴出放大 2~3 倍的预览图，倍数可在设置里调节，便于浏览
- **线路优化**（新增）：API 线路一键测速并选最快；图片线路失败自动切换
- **空间统计与清理**（新增）：统计下载 / 导出 / 日志占用，清理下载残留、分享包、旧日志
- **配置分区**（扩展）：下载 / 网络 / 导出 / 空间 / 界面

## ⬇️ 下载

到 [**Release 页面**](https://github.com/Slumber999/JMComic-Shelf/releases) 下载 Windows 免安装单文件 exe，双击即可运行（需要系统自带 WebView2，Win10/11 一般都有）。

## 📁 数据目录

Windows 下默认在 `%APPDATA%\com.slumber999.jmcomic-shelf`：

- `config.json`：配置（下载 / 导出目录、并发、代理、线路等）
- `漫画下载`：下载目录（每本一个文件夹，含 `元数据.json` 与封面）
- `漫画导出`：导出目录（cbz / pdf / 快速阅读器分享包）
- `下载任务.json`：未完成的下载任务（关软件后可恢复）
- `导出任务.json`：未完成的导出任务（关软件后可恢复）
- `日志`：运行日志

## 🛠️ 如何构建

前提：[Rust](https://www.rust-lang.org/tools/install)、[Node](https://nodejs.org/en)、[pnpm](https://pnpm.io/installation)

```bash
git clone https://github.com/Slumber999/JMComic-Shelf.git
cd JMComic-Shelf
pnpm install

# 开发模式（改前端热更新）
pnpm tauri dev

# 打包：exe + NSIS 安装包
pnpm tauri build --bundles nsis

# 只想要免安装 exe，不打安装包（产物在 src-tauri/target/release/）
pnpm build
pnpm tauri build --no-bundle
```

跑测试：

```bash
cd src-tauri
cargo test --lib
```
